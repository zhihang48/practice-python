\# BMI 计算器（Python）

\## 项目简介

Python 编写的BMI身体质量指数计算小程序。

自带输入校验：

\- 输入文字会提示错误，支持重新输入

\- 禁止输入0和负数，防止异常

\- 结果保留2位小数



\## 使用方法

1\. 源码运行：`python BMI-Github.py`

2\. 打包版本：直接双击 BMI-Github.exe

3\. 根据提示输入体重(kg)、身高(m)

4\. 程序输出BMI数值和体型判断



\## BMI判定标准

\- ≤18.5：偏瘦

\- 18.5 < BMI ≤25：正常

\- 25 < BMI ≤30：偏胖

\- >30：肥胖
